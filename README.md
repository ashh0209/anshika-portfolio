# Anshika Kumari — Personal Portfolio

A clean, responsive personal portfolio website for **Anshika Kumari**, BBA-DBE student at IIM Bangalore.

## Overview

A single-page portfolio built with vanilla HTML and CSS, featuring smooth scroll animations, a fixed navigation bar, and a professional navy/gold design system.

## Sections

- **Hero** — Introduction with a profile summary card
- **About** — Background, skills overview, and contact details
- **Education** — IIM Bangalore, BBA in Digital Business & Entrepreneurship (2025–2028)
- **Experience** — McKinsey Forward Program, SRCC Economics Club, IIT Roorkee Campus Ambassador
- **Achievements** — 6 competition highlights including 1st place at IIM-B Innovators and Top 7 nationally at IIM Lucknow InvestorWise
- **Skills** — Technical (Python, Excel, ML, Financial Modelling) and soft skills
- **Interests** — Personal interests and hobbies
- **Contact** — Email, phone, and LinkedIn

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, CSS Grid, Flexbox, scroll-driven animations
- **Fonts** — Playfair Display (serif headings) + Inter (body) via Google Fonts

## Project Structure

```
anshika portfolio/
├── index.html
└── css/
    └── style.css
```

## Running Locally

No build step required. Open `index.html` directly in a browser:

```bash
open index.html
```

Or serve with any static file server:

```bash
npx serve .
```

## Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--navy` | `#0f2240` | Primary color, headings |
| `--gold` | `#b8963e` | Accent, eyebrow labels |
| `--bg` | `#f8f7f4` | Page background |
| `--font-serif` | Playfair Display | Headings |
| `--font-sans` | Inter | Body text |
